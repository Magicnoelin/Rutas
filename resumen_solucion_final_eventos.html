✅ Solución Final Implementada

Problema original: Las páginas tipo https://rutasrurales.io/evento/xxx no mostraban los meta tags correctos en el código fuente estático.

⚠️ Problema Identificado

Al ver el código fuente de https://rutasrurales.io/evento/jornadas-matanza-burgo-osma-2026-gastronomia-soria se veía:



Detalle del Evento | Rutas Rurales

Pero debería ser:



Jornadas de la Matanza 2026 en El Burgo de Osma

✅ Solución Implementada

Enfoque: Generar los meta tags en el servidor (PHP) en lugar de depender de JavaScript.

1. Archivo PHP creado: evento-detalle.php

  • Consulta la base de datos para obtener los datos del evento
  • Genera los meta tags directamente en el servidor
  • Incluye soporte para múltiples idiomas (es, de, en, fr, zh)
  • La canonical es exactamente la URL de la página (sin "www.")

2. Reglas .htaccess actualizadas

# Antes:
RewriteRule ^evento/([^/]+)/?$ evento-detalle.html?slug=$1 [L,QSA]

# Después:
RewriteRule ^(es|de|en|fr|zh)/evento/([^/]+)/?$ evento-detalle.php?slug=$2&lang=$1 [L,QSA]
RewriteRule ^evento/([^/]+)/?$ evento-detalle.php?slug=$1 [L,QSA]

3. Meta tags generados dinámicamente

$meta_title = !empty($evento['meta_title']) ? $evento['meta_title'] : $evento['titulo'] . ' en ' . $evento['localidad'];
$meta_description = !empty($evento['meta_description']) ? $evento['meta_description'] :
(!empty($evento['descripcion_corta']) ? $evento['descripcion_corta'] :
'Descubre eventos culturales en Rutas Rurales...');
$short_description = !empty($evento['descripcion_corta']) ? $evento['descripcion_corta'] : $meta_description;
$canonical_url = "https://rutasrurales.io/evento/" . $evento['slug'];
