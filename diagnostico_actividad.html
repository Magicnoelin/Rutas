Resumen de Problemas Conocidos y Soluciones

  • Problema: El archivo actividad.html no detectaba correctamente el slug de URLs limpias.
  • Solución: Se actualizó el JavaScript para detectar slugs desde: window.currentSlug, parámetros URL, y extracción de path.
  • Problema: Falta de JavaScript para cargar y mostrar datos de actividad.
  • Solución: Se implementó JavaScript completo para cargar datos desde /api/actividad.php.
  • Problema: El archivo actividad-slug.php consultaba la tabla incorrecta (activities en lugar de tourist_activities).
  • Solución: Se corrigió la consulta SQL para usar la tabla correcta.
  • Problema: Falta de archivo .htaccess para manejar URLs limpias.
  • Solución: Se creó el archivo .htaccess con las reglas de reescritura correctas.

Instrucciones para el Servidor

  1. Asegurarse de que el archivo .htaccess esté en el directorio raíz del sitio web.
  2. Verificar que el módulo mod_rewrite de Apache esté habilitado.
  3. Confirmar que las actividades existan en la tabla tourist_activities de la base de datos.
  4. Verificar que las actividades tengan is_active = 1 y moderation_status = 'approved'.
  5. Probar las URLs:
    • https://www.rutasrurales.io/actividad/kayak-cuerda-del-pozo
    • https://www.rutasrurales.io/actividad/micologia-picos-urbion
    • https://www.rutasrurales.io/actividad.html?slug=kayak-cuerda-del-pozo (formato antiguo)
