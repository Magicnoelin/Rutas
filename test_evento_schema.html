🧪 Test de Validación - Schema.org para Eventos

📋 Instrucciones

Este archivo te ayuda a verificar que el JSON-LD de eventos se genera correctamente con el campo endDate.

  1. Opción 1 - Validar URL en vivo:
    • Sube el archivo evento-detalle.html al servidor
    • Abre cualquier evento en el navegador
    • Copia la URL completa
    • Pégala en las herramientas de validación abajo
  2. Opción 2 - Validar código fuente:
    • Abre un evento en el navegador
    • Presiona Ctrl+U (Ver código fuente)
    • Busca <script type="application/ld+json" id="event-schema">
    • Copia el JSON completo
    • Pégalo en el validador de Schema.org

✅ Checklist de Verificación

  • ☐ El JSON-LD contiene el campo "endDate"
  • ☐ El formato de fecha es ISO 8601 (ej: 2026-02-08T10:00:00+01:00)
  • ☐ Si end_date está vacío, endDate = startDate
  • ☐ Todos los campos requeridos están presentes (name, startDate, endDate, location)
  • ☐ Google Rich Results Test no muestra errores
  • ☐ Schema.org Validator no muestra errores

📝 Ejemplo de JSON-LD Correcto

{
  "@context": "https://schema.org",
  "@type": "Event",
  "name": "Festival de Música Folk",
  "description": "Festival anual de música tradicional",
  "startDate": "2026-07-15T19:00:00+01:00",
  "endDate": "2026-07-15T23:00:00+01:00",
  "eventStatus": "https://schema.org/EventScheduled",
  "eventAttendanceMode": "https://schema.org/OfflineEventAttendanceMode",
  "location": {
    "@type": "Place",
    "name": "Plaza Mayor",
    "address": {
      "@type": "PostalAddress",
      "streetAddress": "Plaza Mayor, 1",
      "addressLocality": "Soria",
      "addressRegion": "Soria",
      "addressCountry": "ES"
    }
  },
  "image": "https://rutasrurales.io/images/festival.jpg",
  "url": "https://rutasrurales.io/evento/festival-folk-2026",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "EUR",
    "availability": "https://schema.org/InStock"
  }
