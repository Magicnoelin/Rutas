Test de Meta Tags para Eventos

Cambios realizados en evento-detalle.html:

  1. Meta tag short_description añadido: Se añadió en el head
  2. Canonical sin www: Se cambió de https://www.rutasrurales.io/evento-detalle.html a https://rutasrurales.io/evento-detalle.html
  3. Actualización dinámica en JavaScript: En la función renderEvento() se añadió: 
    // Actualizar  con descripcion_corta
const shortDescMeta = document.querySelector('meta[name="short_description"]');
if (shortDescMeta && evento.descripcion_corta && evento.descripcion_corta.trim() !== '') {
    shortDescMeta.setAttribute('content', evento.descripcion_corta.trim());
}

// Actualizar canonical URL dinámicamente con el slug del evento
// SIN "www." como solicitado
const canonicalEl = document.getElementById('dynamic-canonical');
if (canonicalEl && evento.slug) {
    const lang = window.currentLang || 'es';
    const canonicalUrl = lang !== 'es'
        ? 'https://rutasrurales.io/' + lang + '/evento/' + evento.slug
        : 'https://rutasrurales.io/evento/' + evento.slug;
    canonicalEl.setAttribute('href', canonicalUrl);
}

Verificación:

Para verificar los cambios, puedes:

  • Abrir evento-detalle.html en el navegador y ver el código fuente
  • Verificar que el canonical no tiene "www."
  • Verificar que existe el meta tag short_description
  • Probar con un slug de evento real para ver que se actualizan dinámicamente

Ejemplo de URLs afectadas:
