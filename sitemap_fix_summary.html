📋 Resumen de Corrección: Sitemap Eventos

Fecha: 4 de abril de 2026

Problema reportado: "sitemap-eventos.xml, está mal recoge los eventos pasados y no los futuros, ademas no toma las tradccuiones cultural_events_trads"

PROBLEMA 1 Lógica incorrecta de fechas

El sitemap estaba incluyendo eventos pasados en lugar de eventos futuros.

Código anterior:

AND COALESCE(e.end_date, DATE_ADD(e.start_date, INTERVAL 1 DAY)) >= CURDATE()

Problema: Esta lógica podía incluir eventos que ya habían terminado, especialmente cuando end_date era NULL y start_date estaba en el pasado.

SOLUCIÓN 1 Lógica corregida de fechas

Se cambió la lógica para incluir solo eventos futuros o actuales:

AND (
  (end_date IS NULL AND start_date >= CURDATE()) OR
  (end_date IS NOT NULL AND end_date >= CURDATE())
)

Explicación:

  • Para eventos sin fecha de fin: se incluyen si empiezan hoy o después
  • Para eventos con fecha de fin: se incluyen si terminan hoy o después

PROBLEMA 2 No tomaba traducciones de cultural_events_trads

El sitemap no estaba incluyendo correctamente las traducciones de eventos.

SOLUCIÓN 2 Mejora en el manejo de traducciones

Se mejoraron las consultas para asegurar que:

  • Se obtengan todas las traducciones activas de la tabla cultural_events_trads
  • Se aplique la misma lógica de fechas a las traducciones
  • Se incluyan correctamente las etiquetas hreflang para SEO multilingüe

📁 Archivos modificados

  • sitemap-eventos.php - Sitemap principal de eventos
  • sitemap-eventos-idiomas.php - Sitemap de traducciones de eventos
  • generar-sitemap.php - Generador de sitemaps dinámicos
  • admin_tablas/cron/regenerar_sitemap_i18n.php - Script de regeneración de sitemap

✅ Verificación recomendada

Para verificar que la corrección funciona:

  1. Acceder a https://www.rutasrurales.io/sitemap-eventos.php
  2. Verificar que solo aparezcan eventos futuros o actuales
  3. Verificar que aparezcan las etiquetas para traducciones
  4. Acceder a https://www.rutasrurales.io/sitemap-eventos-idiomas.php
  5. Verificar que aparezcan todas las traducciones de eventos futuros

📝 Notas técnicas

  • La lógica de fechas ahora es consistente en todos los archivos de sitemap
  • Se mantiene la compatibilidad con eventos que no tienen fecha de fin (end_date IS NULL)
  • Las traducciones se obtienen correctamente de la tabla cultural_events_trads
  • Se mejoraron los comentarios en el código para mayor claridad
