Problema Identificado

El usuario reportó que en la página https://rutasrurales.io/evento/jornadas-matanza-burgo-osma-2026-gastronomia-soria:

  • La canonical NO era la misma URL de la página
  • El meta name estaba mal
  • El title también estaba mal

Cambios en evento-detalle.html

1. Meta tag short_description añadido

✓ AÑADIDO en la sección head:

2. Canonical inicial actualizado

✓ ACTUALIZADO de https://rutasrurales.io/evento-detalle.html a:

3. Lógica de canonical dinámica mejorada

✓ MEJORADO en la función renderEvento():

// Actualizar canonical URL dinámicamente con la URL actual de la página // La canonical debe ser exactamente la misma URL que se está viendo const canonicalEl = document.getElementById('dynamic-canonical'); if (canonicalEl) { // Usar la URL actual completa (incluyendo www. si está presente) const canonicalUrl = window.location.href; canonicalEl.setAttribute('href', canonicalUrl); }

IMPORTANTE: Ahora usa window.location.href para obtener la URL exacta de la página, incluyendo "www." si está presente.

4. Actualización dinámica de short_description

✓ IMPLEMENTADO en la función renderEvento():

// Actualizar con descripcion_corta const shortDescMeta = document.querySelector('meta[name="short_description"]'); if (shortDescMeta && evento.descripcion_corta && evento.descripcion_corta.trim() !== '') { shortDescMeta.setAttribute('content', evento.descripcion_corta.trim()); }

¿Cómo funciona ahora?

  1. Cuando un usuario visita https://rutasrurales.io/evento/mi-evento-slug
  2. El .htaccess redirige internamente a evento-detalle.html?slug=mi-evento-slug
  3. JavaScript carga los datos del evento desde la API
  4. La función renderEvento() actualiza:
    • El título de la página con evento.meta_title o evento.titulo
    • El meta description con evento.meta_description o evento.descripcion_corta
    • El meta short_description con evento.descripcion_corta
    • La canonical con la URL exacta de la página (window.location.href)
