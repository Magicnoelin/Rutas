2. API de Comentarios

GET /api/place_of_interest-comentarios.php

Endpoint: /api/place_of_interest-comentarios.php?place_id=123

Funcionalidades:

  • Listar comentarios con paginación
  • Contar comentarios: ?place_id=123&count=1
  • Obtener valoración promedio
  • Respuestas anidadas

POST /api/place_of_interest-comentarios.php

Body JSON:

{
  "place_id": 123,
  "author_name": "Juan Pérez",
  "author_email": "juan@example.com",
  "comment_text": "Excelente lugar!",
  "rating": 5,
  "parent_id": null
}

Características:

  • Validación de campos
  • Anti-spam (1 comentario/60s por IP)
  • Generación automática de avatar
  • Moderación automática (is_approved = 1)

6. Instrucciones de Uso

Para probar en producción:
  1. Visitar cualquier página de lugar, ej: https://www.rutasrurales.io/lugar/restaurante-alameda-fuenmayor-la-rioja

  4. Probar a dejar un comentario con valoración
  5. Probar a responder a un comentario existente
  6. Verificar que la paginación funciona
⚠️ Notas importantes:
  • La tabla place_of_interest_comments se crea automáticamente al primer uso
  • El sistema usa resource_type = 'place' en resource_stats
  • Los comentarios se aprueban automáticamente (is_approved = 1)
  • Se aplican límites anti-spam: 1 comentario/60s y 10 comentarios/día por IP
