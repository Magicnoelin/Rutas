🚀 PASOS PARA PONER EN MARCHA
═══════════════════════════════════════════════════════════════════

PASO 1: Ejecutar SQL
  → Acceder a phpMyAdmin
  → Ejecutar: api/crear_sistema_billing.sql
  → Verificar: "Sistema de facturación creado exitosamente"

PASO 2: Verificar Instalación
  → Acceder a: https://rutasrurales.io/api/diagnostico_billing.php
  → Verificar que todas las tablas estén en verde
  → Verificar billing_concepts 12 y 15

PASO 3: Configurar Stripe
  → Crear cuenta en: https://dashboard.stripe.com/register
  → Obtener claves API: https://dashboard.stripe.com/test/apikeys
  → Editar: api/stripe_config.php
  → Pegar claves: pk_test_... y sk_test_...

PASO 4: Configurar Webhook
  → Ir a: https://dashboard.stripe.com/test/webhooks
  → Añadir endpoint: https://rutasrurales.io/api/stripe_webhook.php
  → Seleccionar eventos (ver documentación)
  → Copiar webhook secret (whsec_...)
  → Actualizar en: api/stripe_config.php

PASO 5: Integrar en Frontend
  → Incluir: <script src="https://js.stripe.com/v3/"></script>
  → Incluir: <script src="/js/payment-integration.js"></script>
  → Usar: upgradeToPremium('monthly') o upgradeToPremium('yearly')

═══════════════════════════════════════════════════════════════════
🔗 VINCULACIÓN AUTOMÁTICA
═══════════════════════════════════════════════════════════════════

El sistema vincula automáticamente:

Premium Mensual (9.99€):
  plan_id: 2 → billing_concept_id: 12 → billing_cycle: monthly

Premium Anual (99.99€):
  plan_id: 2 → billing_concept_id: 15 → billing_cycle: yearly

Cuando el usuario paga:
  1. Se crea membership_upgrade_intent
  2. Stripe procesa el pago
  3. Webhook actualiza user_subscriptions
  4. Se vincula a billing_concept correspondiente
  5. Se actualiza membership_type en users

📋 VERIFICACIÓN EN BASE DE DATOS
═══════════════════════════════════════════════════════════════════

-- Ver billing concepts
SELECT * FROM billing_concepts WHERE id IN (12, 15);

-- Ver planes de membresía
SELECT * FROM membership_plans;

-- Ver intenciones de upgrade
SELECT * FROM membership_upgrade_intents ORDER BY created_at DESC LIMIT 10;

-- Ver usuarios Premium
SELECT id, email, membership_type, membership_status 
FROM users WHERE membership_type = 'Premium';

-- Ver suscripciones activas
SELECT * FROM user_subscriptions WHERE status = 'active';

-- Ver pagos recibidos
SELECT * FROM payments ORDER BY created_at DESC LIMIT 10;
