Test de Corrección de Header/Footer en Móvil

Problema Identificado

Las páginas de detalle de lugares (ej: /lugar/acenas-de-olivares-molinos-duero) no mostraban correctamente el header y footer en vista móvil.

✓ El problema era que las plantillas lugar-interes.html y detalle.html tenían sus propios headers/footers hardcodeados que no eran responsivos.

Solución Implementada

Se modificó redirect_manager.php para:

  1. ✓ Inyectar el header responsivo de header.php para tipos lugar y alojamiento
  2. ✓ Inyectar el footer responsivo de footer.php para tipos lugar y alojamiento
  3. ✓ Mantener la funcionalidad existente para tipo actividad (que ya usaba placeholders)

Cambios Técnicos

Archivo modificado: redirect_manager.php

Líneas modificadas: ~133-147 (original) → ~133-180 (nuevo)

Lógica añadida:

// INYECTAR HEADER Y FOOTER PARA TODAS LAS PÁGINAS (LUGAR, ALOJAMIENTO, ACTIVIDAD)
if ($type === 'lugar' || $type === 'alojamiento' || $type === 'actividad') {
    // Obtener contenido del header y footer
    if ($type === 'actividad') {
        // Para actividad, reemplazar marcadores existentes
        $html = str_replace('', $headerContent, $html);
        $html = str_replace('', $footerContent, $html);
    } else {
        // Para lugar y alojamiento, reemplazar el header y footer existentes
        // usando regex para encontrar y reemplazar las secciones
        $headerPattern = '/]*\bclass\s*=\s*["\']header["\'][^>]*>.*?<\/header>/is';
        $html = preg_replace($headerPattern, $headerContent, $html, 1);
        
        $footerPattern = '/]*\bclass\s*=\s*["\']footer["\'][^>]*>.*?<\/footer>/is';
        $html = preg_replace($footerPattern, $footerContent, $html, 1);
        
        // Patrones de respaldo por si los primeros no funcionan
        if (strpos($html, $headerContent) === false) {
            $headerPattern2 = '/]*\bclass\s*=\s*["\'][^"\']*header[^"\']*["\'][^>]*>.*?<\/header>/is';
            $html = preg_replace($headerPattern2, $headerContent, $html, 1);
        }
        
        if (strpos($html, $footerContent) === false) {
            $footerPattern2 = '/]*\bclass\s*=\s*["\'][^"\']*footer[^"\']*["\'][^>]*>.*?<\/footer>/is';
            $html = preg_replace($footerPattern2, $footerContent, $html, 1);
        }
    }
}

Beneficios de la Corrección

  • ✓ Header responsivo en móvil con diseño compacto (grid de 4 columnas)
  • ✓ Header fijo en la parte superior en móvil (position: fixed)
  • ✓ Footer responsivo con diseño adaptativo
  • ✓ Consistencia visual en todas las páginas del sitio
  • ✓ Mejor experiencia de usuario en dispositivos móviles

Notas Importantes

⚠ La solución usa regex para reemplazar las secciones de header/footer. Esto es robusto pero depende de la estructura HTML consistente.

✓ Se incluyen patrones de respaldo para manejar variaciones en los atributos class.

✓ La funcionalidad para actividades (que ya usaba placeholders) se mantiene intacta.
