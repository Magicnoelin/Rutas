4. Instrucciones para probar página real

Para diagnosticar la página real de actividad:

  1. Abre /actividad/kayak-cuerda-del-pozo
  2. Presiona F12 para abrir las herramientas de desarrollador
  3. Ve a la pestaña "Console" (Consola)
  4. Busca errores en rojo
  5. Comparte cualquier error que veas

Errores comunes a buscar:

  • Uncaught SyntaxError - Error de sintaxis en JavaScript
  • Uncaught ReferenceError - Variable o función no definida
  • Failed to load resource - Archivo no encontrado
  • Cross-Origin - Problema de CORS
