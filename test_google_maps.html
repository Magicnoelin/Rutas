🔐 Pasos para obtener una clave de API:

  1. Ve a Google Cloud Console
  2. Crea un nuevo proyecto o selecciona uno existente
  3. Habilita la API "Maps JavaScript API"
  4. Ve a "Credenciales" y crea una nueva clave de API
  5. Restringe la clave a tu dominio para mayor seguridad
  6. Reemplaza la clave en el código
